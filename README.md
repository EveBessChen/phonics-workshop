## 首页视频介绍

点右下角女老师头像（或「查看视频」）→ 弹出视频层播放片头；右上角「跳过视频」直接回主页，播完也会自动回主页。

- **只有当天第一次打开首页才自动播**（`localStorage` 键 `pw_intro_day` 存当天日期）。从年级页 / 错词本 / 报告页返回首页、浏览器后退、刷新，都**不会**再自动播。
  - 站内所有「‹ 首页」链接都写成 `index.html#back`，index 见到 `#back` 就不播；另外还看 `performance` 的导航类型（`back_forward` / `reload`）兜底。
- 浏览器策略拦截「带声音的自动播放」时，画面中间会出现一个大播放键，点一下就播（这样孩子听到的是有声音的版本）。
- 视频文件是本地相对路径 `intro.mp4`，**断网也能播**；换视频就替换同名文件即可。
- **不点开就不下载**：`<video preload="none">` 且 `src` 在点头像时才挂上去，所以首页本身 0 字节视频流量（实测打开首页的视频请求数 = 0），不会白耗流量。

## 本地打开（记录要能保存）

- 推荐：**双击 `打开拼读小工坊.command`** —— 会在本机起一个 `http://127.0.0.1:8765` 的小服务并打开浏览器（有 Chrome 会优先用 Chrome）。这样 6 个页面共用一个网址，错词本 / 学习报告一定能存住，**关掉浏览器再打开也还在**；重复双击会复用同一个端口，不会越开越多。
- 直接双击 `index.html`（file:// 方式）在 Chrome 里也能存；但 **Safari 直接打开本地文件时不允许网页存数据**，练习记录存不住。
- 「存储保险 v2」（六个页面 head 里第一段脚本）：
  - 先探一下 `localStorage` 能不能写；能写就什么都不改。
  - 不能写时（Safari 双击本地文件、沙箱 iframe 等），把存储接口换到 **`window.name`** —— 它是这个标签页独有的一小块字符串，**页面之间跳转不会丢**。于是「玩完 → 点错词本 / 学习报告 / 回首页」这次都能读到记录；关掉标签页才清空。视频「当天只自动播一次」也靠它记日期，不会每回一次首页就重播。
  - 同时在首页 / 错词本 / 报告页底部弹**一次**提示条（同一个标签页只弹一次，14 秒自动消失），说明怎么换成能长期保存的方式；游戏页不弹，免得挡住「下一个」。

## 拼读分类规则（2026-10-26 修正）

- **CVC 短元音**：只收**三个字母、辅音+元音+辅音、单元音短音**的词（cat / dog / sun / bus…）。`dress`、`stop`、`shop`、`which`、`hand`、`duck` 这类四字母或多音节词不再算 CVC（它们归到「辅音组合」或「多音节长词」）。
- **长元音**：优先收 **silent e（词尾 e 不发音）** 的单音节词（name / kite / phone / rope / twice…），另保留 `-old / -ind / -ild / -igh` 等字母音例外词（old / cold / kind / child）。
- 只重算了 `cvc` 与 `long` 两个标签，其余标签（元音组合 / 元音+r / 辅音组合 / 多音节 / 特殊拼读）保持原样；某词去掉 cvc 后若一个标签都不剩，会按「多音节 → 辅音连缀 → 特殊拼读」补一个，保证仍能在筛选里出现。

## 四种玩法

- **找一找**：看图 + 听整词发音，四个选项里挑正确的那个
- **拼一拼**：听音后按牛津拼读规则把音块逐个拼成单词
- **慢速怎么算才不「出错」**：原来整词按 0.55 倍速播放，音高被压掉近一个八度，听上去像换了个词。现在
  - 找一找的「🐢 慢速」= 整词 **0.74 倍速**（清楚，但不变形）；
  - 拼一拼的「🐢 慢速拼读」= 先**一块一块**慢读（0.82 倍速，每块 0.21 秒间隔，格子会跟着亮），最后再整词慢读一遍 —— 孩子能把听到的每个音对到字母块上。
  - 三册共 329 个词、1336 次音块播放都逐个跑过：顺序、倍速、对应音频全部逐条核对通过。
- **默一默**（右侧栏）：点单词就直接听音，在纸上默写，写完再切到「拼一拼」拼出来对答案
  - 成人模式 / 拼一拼模式下，**点这一行的任何地方都会朗读这个词**（不跳走），喇叭按钮也放大了；点完会闪一下表示「读到了」。
  - 挑战模式下点一行是「跳到这个词」。
- **成人模式**（右上角开关）：直接显示单词与中文，家长/老师陪读时用

## 练习记录（错词本 / 学习报告）

- 记录写在浏览器本地 `localStorage`，键名 `phonicsWorkshop_v1`，**不联网、不上传**。
- 数据结构：`{ kid, data: { g3|g4|g5: { w:{错词:次数}, r:{词:累计答对}, s:星星, d:{日期:{s,r,w}} } } }`
- 错词：找一找选错 / 拼一拼点错顺序块时 +1；同一词大小写不同会归并成一条。
- **只记被考的那个词**：点错的那几个干扰选项（比如考 hand 却点了 ear）**不会**被记进错词本；同一个词在同一轮里不管点错几次都只 +1（下一轮再错才 +2）。这条在找一找、拼一拼两个玩法里都生效。
- 换设备、清缓存、无痕模式都会看不到记录；iPhone 建议「添加到主屏幕」，否则 Safari 可能 7 天不动就清掉本地数据。

## 技术要点

- **零外部依赖**：每个年级一个独立 HTML，内嵌全部 CSS / JS / 音频（base64），拷走就能用
- **整词朗读**：Microsoft Edge TTS（`en-GB-LibbyNeural`，语速 −12%）
- **音块拼读**：Piper（`en_US-lessac-medium`）直接喂 IPA 音素生成
- **清擦音修复**：Piper 拉长 /s/ /ʃ/ /f/ /θ/ 时会在中后段补出一段低频杂音，孩子会听成「st / t」；
  做法是取更长素材 → 按高频能量裁掉低频尾巴 → 再高通过滤残留。
  低频污染比 `/s/` 11.3→2.5、`/ʃ/` 60→0.6、`/f/` 215→3.1、`/θ/` 14→5.2，时长反而从 93ms 增到约 230ms
- **牛津 Phonics 切分规则**：digraph 合并（sh / ch / th / ph / ng / nk / ck / qu / ai / ee / oa…），
  blend 拆开（tr / bl / gr / st…）；r 后接元音则发音归后一块，r 后接辅音或在词尾则与前面元音合并
