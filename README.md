## 四种玩法

- **找一找**：看图 + 听整词发音，四个选项里挑正确的那个
- **拼一拼**：听音后按牛津拼读规则把音块逐个拼成单词
- **默一默**（右侧栏）：点单词就直接听音，在纸上默写，写完再切到「拼一拼」拼出来对答案
- **成人模式**（右上角开关）：直接显示单词与中文，家长/老师陪读时用

## 技术要点

- **零外部依赖**：每个年级一个独立 HTML，内嵌全部 CSS / JS / 音频（base64），拷走就能用
- **整词朗读**：Microsoft Edge TTS（`en-GB-LibbyNeural`，语速 −12%）
- **音块拼读**：Piper（`en_US-lessac-medium`）直接喂 IPA 音素生成
- **清擦音修复**：Piper 拉长 /s/ /ʃ/ /f/ /θ/ 时会在中后段补出一段低频杂音，孩子会听成「st / t」；
  做法是取更长素材 → 按高频能量裁掉低频尾巴 → 再高通过滤残留。
  低频污染比 `/s/` 11.3→2.5、`/ʃ/` 60→0.6、`/f/` 215→3.1、`/θ/` 14→5.2，时长反而从 93ms 增到约 230ms
- **牛津 Phonics 切分规则**：digraph 合并（sh / ch / th / ph / ng / nk / ck / qu / ai / ee / oa…），
  blend 拆开（tr / bl / gr / st…）；r 后接元音则发音归后一块，r 后接辅音或在词尾则与前面元音合并
